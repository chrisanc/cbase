# **AI Codebase Engine: Sentinel**
**Sentinel** is not just another linter, it's the solution of all your project problems
and vulnerabilities. The goal of this tool is to help developers to detect anomalies in
their code and fix them as quick as possible.

With AI integration, the code fixing has never been easier. A local AI model will be trained
with your project and will be used to suggest you improvements and security fixes.

Written purely in Java to demonstrate the language is POWERFUL!.

Used libraries such as:
- Picocli
- ANTLR
